# Privacy / Privasi

<details open>
<summary><b>English</b></summary>

- No backend, account, analytics, or trackers.
- JSON files are read in the browser and kept in memory only. They are never uploaded.
- The website uses a CSP that forbids outgoing connections.
- The extension only communicates with instagram.com using your own login session, and only when you press the Check button.
- Local history (if enabled) is stored only on your device and can be deleted at any time.

The code is open, so every claim above can be audited by you.

</details>

<details>
<summary><b>Bahasa Indonesia</b></summary>

- Tidak ada backend, akun, analytics, atau pelacak.
- File JSON dibaca di browser dan hanya disimpan di memori. Tidak pernah diunggah.
- Website memakai CSP yang melarang koneksi keluar.
- Extension hanya berkomunikasi dengan instagram.com memakai sesi login milikmu sendiri, dan hanya saat kamu menekan tombol Cek.
- Riwayat lokal (jika diaktifkan) disimpan hanya di perangkatmu dan bisa dihapus kapan saja.

Kodenya terbuka, jadi semua klaim di atas bisa kamu audit sendiri.

</details>
