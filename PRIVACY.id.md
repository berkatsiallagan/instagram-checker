# Privasi

[English](PRIVACY.md) · [Bahasa Indonesia](PRIVACY.id.md)

- Tidak ada backend, akun, analytics, atau pelacak.
- File JSON dibaca di browser dan hanya disimpan di memori. Tidak pernah diunggah.
- Website memakai CSP yang melarang koneksi keluar.
- Extension hanya berkomunikasi dengan instagram.com memakai sesi login milikmu sendiri, dan hanya saat kamu menekan tombol Cek.
- Riwayat lokal (jika diaktifkan) disimpan hanya di perangkatmu dan bisa dihapus kapan saja.

Kodenya terbuka, jadi semua klaim di atas bisa kamu audit sendiri.
